A Python program (standard library only) that draws the front page of "The World Today" for Monday 23 November 2026 and writes it to entry.png.
The COP31 collapse in Antalya leads, with panels on the Hormuz escalation, the first drone strike on Russia's Baltic fleet and the failed Jerusalem unity talks, twelve regional cards and a Day in Numbers strip.
Its own 5x7 bitmap font and PNG encoder make the same bytes on every run: no clock, no randomness, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
